# Security policy

## Reporting a security issue

Please do not publish API tokens, tenant URLs, customer configuration, or sensitive export artifacts in public issues. Remove secrets and customer-identifying data before sharing logs or screenshots. For a suspected vulnerability, contact the repository maintainer privately through the contact method listed on the GitHub profile.

## Handling sensitive data

Exports and logs may contain tenant-specific details. Keep them local and access-controlled, and review all files before attaching them to an issue or support request. Revoke and replace any API token that may have been exposed.
